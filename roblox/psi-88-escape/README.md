# PSI 88층 탈출 — 로블록스 맵

평행세계 PSI 건물을 위에서부터 아래로 탈출하는 맵이에요. 88층에서 시작해서 1층 정문으로 나가는 구조이고, 정문 열쇠는 지하 맨 밑(지구 내핵)에 있어요.

- **맵 파일**: `PSI_88F_Escape_Map.rbxlx` (로블록스 스튜디오 → 파일 → 열기)
- **제작 범위**: 맵만 (스크립트 없음). 나중에 스크립트를 붙이기 쉽게 문, 버튼, 열쇠 같은 곳에 이름과 **태그**를 달아 두었어요.
- **스타일**: 실사풍. Future 조명, 붉은 대기, 반사광 사용
- **인원**: 6명 (88층 방 6개에 스폰 6개)

## 이동 구조

- 건물 동쪽에 **계단실이 1층부터 꼭대기까지 이어져** 있어요. 각 층 계단 문(`StairDoor`)은 열려 있어서, 계단으로 내려오면 그 층에 들어갈 수 있어요.
- **다음 층으로 내려가는 계단은 쇠창살 문(`ExitGate`)으로 막혀** 있어요. 그 층 퍼즐을 풀면 열리게 스크립트를 짜면 돼요. 단, 1층에서 지하로 가는 길은 열려 있어요.
- 88층은 현관 자체가 쇠사슬로 잠겨 있어요 (`StairDoor`, 잠김).
- 엘리베이터는 장식이에요 (운행 중지, 고장, 정전 같은 표시만 있음).

## 스크립터용 태그 (CollectionService)

| 태그 | 위치 | 용도 |
|---|---|---|
| `PlayerSpawn` | 88F 방 6개 | 시작 스폰 (SpawnLocation) |
| `StairDoor` | 모든 층 | 층 ↔ 계단실 문 |
| `ExitGate` | 88F, 1F, B13 빼고 전부 | 아래층 계단을 막는 창살 |
| `ExitButton` | 66F 골인, 40F 분전반 | 누르면 창살이 열리는 버튼 |
| `Checkpoint` | 66F | 점프 맵 체크포인트 |
| `KillBrick` | 66F 짜장, 내핵 용암 | 닿으면 죽거나 체크포인트로 이동 |
| `ChaserSpawn` | 50F 조수민 방, 10F 낮잠방 | 조수민 추격자가 나타나는 위치 |
| `MainGate` / `KeySlot` | 1F 정문 | 정문 막는 벽 / 열쇠 꽂는 곳 |
| `Key` | 내핵 | 정문 열쇠 |
| `VaultDoor`, `Safe`, `CellBars`, `SpecialTie`, `JjangkeunBerry` | 80F, 20F, B12, B1, B3 | 퍼즐 소품 |

## 바로 둘러보는 법 (테스트용)

창살과 잠긴 문 때문에 그냥 플레이하면 88층에서 못 나가요. 스튜디오 **명령 모음(Command Bar)**에 아래 코드를 붙여넣으면 전부 사라져요 (되돌리려면 Ctrl+Z).

```lua
local CS = game:GetService("CollectionService")
for _, tag in ipairs({"ExitGate", "StairDoor", "MainGate"}) do
	for _, obj in ipairs(CS:GetTagged(tag)) do obj:Destroy() end
end
```

## 퍼블리시할 때 설정

- **게임 설정 → 플레이어 → 최대 플레이어 수: 6**. 이 값은 맵 파일에 저장되지 않아서 직접 설정해야 해요.
- `Workspace.StreamingEnabled`는 켜 두었어요 (모바일 최적화). 층이 많아서 가까운 층만 불러와요.

## 제가 임의로 정한 부분 (마음에 안 들면 말해 주세요)

- **80·60·40·30·20·10층** 테마는 제가 지었어요.
- **기니방**은 '기니피그 방'으로 해석했어요.
- **짱큰베리**는 '변이 베리 온실'로 만들었어요.
- **50층**은 조수민 하우스 하나만 넣었어요. 목록에 두 번 적혀 있던 빈 50층 칸은 비워 뒀어요.
- **지구 내핵**에 정문 열쇠를 두었어요.
- **B4, B5**는 건너뛰었어요. 계단에 "출입 불가"로 표시돼 있어요.

## 한계

- 업로드한 에셋 없이 **파트(블록, 원기둥, 공, 쐐기)로만** 만들었어요. 그래서 메시, 텍스처, 사운드가 없어요. 가구 같은 건 나중에 툴박스 모델이나 직접 만든 메시로 바꾸면 더 고퀄이 돼요.
- 파트 약 66,000개(그중 약 38,000개는 충돌 없는 장식), 파일 크기 약 46MB예요.
- `StreamingEnabled`로 가까운 층만 불러와서 실제 플레이 부담은 훨씬 작아요.

## 디테일 구성 방식

맵은 세 겹으로 채워져 있어요.

1. **층 기본 구조** (`floors_*.py`): 벽, 방, 큰 가구, 퍼즐 장치
2. **사연 장면** (`vignettes.py`): 층마다 손으로 짠 장면
   - 88층: 현관 옆 바리케이드, 빨래 건조대, 밥상, 천장 누수 양동이, 탈출 가방, 라면 박스 탑
   - 87층: 비계, 출입 금지 테이프, 떨어진 덕트, 에스키모의 사과 카드
   - 50층: 현관까지 이어진 아이 발자국, 꽃밭, 장난감 흔적, PSI 건물 미니어처
   - 병원층: 복도 손잡이, 방화문, 환자 명단 보드
3. **자동 꾸미기** (`dress.py` + `props2.py`): 층마다 비어 있는 공간을 찾아서 채워요.
   - **벽 쪽 바닥**: 정수기, 복합기, 분리수거함, 서랍장, 화분, 의료 카트 등
   - **벽면**: 포스터, 시계, 소화기, 스위치, 콘센트, 피난 안내도, 누수 얼룩, 금
   - **천장**: 스프링클러, 화재 감지기, 공조 디퓨저
   - **바닥**: 서류, 얼룩, 컵 같은 작은 흔적
   - 문 앞, 계단 앞, 엘리베이터 앞은 비워 둬요. 소품 앞에는 사람이 지나갈 폭을 항상 남겨서 길을 막지 않아요.

## 다시 생성하기

`generator/` 폴더의 파이썬 코드가 맵 전체를 만들어요 (외부 라이브러리 필요 없음).

```bash
python3 generator/main.py   # → PSI_88F_Escape_Map.rbxlx
```

층 내용은 `floors_upper.py` (88~50), `floors_mid.py` (44~1), `floors_lower.py` (B1~내핵)에 있고, 건물 뼈대와 계단은 `building.py`에 있어요.
